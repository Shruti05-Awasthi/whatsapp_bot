# WhatsApp Bot using Flask & Twilio

This project is a WhatsApp automation bot built using **Python (Flask)** and **Twilio WhatsApp API**.

## Features
- Auto reply on WhatsApp
- Category based conversation flow
- Slot suggestion logic
- Webhook based architecture

## Tech Stack
- Python
- Flask
- Twilio WhatsApp API
- ngrok (for local tunneling)

## How it Works
1. User sends `hi` on WhatsApp
2. Bot replies with category options
3. User selects a category
4. Bot responds with relevant message / slot

## Note
This project uses **Twilio WhatsApp Sandbox** for development and testing.
